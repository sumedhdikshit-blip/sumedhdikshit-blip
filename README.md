### 🏠 [Real-Estate-AI-Assistant](https://github.com/sumedhdikshit-blip/Real-Estate-AI-Assistant)
**Stack:** FastAPI · Groq LLM · LangChain · FAISS · HuggingFace Embeddings · CSS
AI-powered real estate assistant using a full RAG pipeline — FAISS vector search + HuggingFace embeddings over property data, with Groq LLM for fast, context-aware responses to property queries.

AI-powered e-commerce chatbot that uses Semantic Router to intelligently classify and route queries between FAQ retrieval and product search — delivering precise answers faster than traditional keyword matching.

### 📈 [ML-Project-Premium-Prediction](https://github.com/sumedhdikshit-blip/ML-Project-Premium-Prediction)

End-to-end machine learning project that predicts insurance premiums based on user data. Covers data preprocessing, feature engineering, model selection, and evaluation.
